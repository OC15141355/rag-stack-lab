# Working journal (template)

Copy privately. One entry per sitting. Keep it short. This becomes your
evidence appendix and stops you redoing work.

```markdown
## <date>, <hh:mm>, <topic>

**Goal this session:** <one line>

**Checked:**
- <command / file / doc URL> → <what it showed> (evidence: <where saved>)

**Learned:**
- <fact> (source)

**Changed my mind about:**
- <before> → <after> because <evidence>

**Still unknown:**
- <question> → ask <role> / check <thing>

**Next:**
- <next step>
```
